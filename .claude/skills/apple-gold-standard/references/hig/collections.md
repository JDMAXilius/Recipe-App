# Collections
URL: https://developer.apple.com/design/human-interface-guidelines/collections
## Summary
A collection shows an ordered set of content in a visual layout, ideal for images. Stick to standard row or grid layouts and make items easy to reach.
## Best practices
- Use the standard horizontal row or grid; avoid attention-seeking custom layouts.
- Use a list instead for text-heavy content.
- Make items easy to choose; pad images so focus/hover effects show and nothing overlaps.
- Defaults: tap to select, touch and hold to edit, swipe to scroll; add gestures only when needed.
- Animate inserts, deletes and reorders for feedback.
## iOS specifics
- Be careful with dynamic layout changes; avoid changing layout while people interact unless they explicitly asked.

## Do / Don't
- Do: 2-column grid of recipe photos with even gutters. / Don't: a scattered, rotated custom layout.
- Do: animated card removal on delete. / Don't: items jumping instantly.
- Do: padding around each photo tile. / Don't: tiles touching edge to edge with overlapping highlights.
- Do: text-only ingredient list as a list. / Don't: text ingredients in a grid of tiles.
- Do: layout switch only after tapping a grid/list toggle. / Don't: grid reflowing while the user scrolls.
